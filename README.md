# 2D Game Development – Godot 4

A learning project for building a 2D game with **Godot 4**.

This repository covers the basics of 2D game development, including:

- Player movement
- Physics and collision detection
- Game objects and scenes
- Input handling
- Godot scripting with GDScript

The project is developed step by step while learning Godot 4 and game development fundamentals.

**Engine:** Godot 4
**Language:** GDScript
